VLLM Predicted Outputs Demo

Predicted Outputs is a way of speeding up LLM generation by using a prediction about the contents of the output to process tokens in parallel. LLMs must process their output tokens one at a time due to the fact that they require the previous token as input. Predicted Outputs allows you to take a guess at the contents of the output, and when you get it right, you can output many tokens for the price of one.

Predicted Outputs uses standard "diff" algorithms to realign your prediction with the output after a miss. Because the cost of mis-prediction is so small, and the benefits of processing tokens in parallel are so large, accurate prediction of even a few lines can speed up your generation, and some use cases stand to get massive speedups of 2x, 10x, or more:

  • Coding agents
  • Document modification
  • Json object mutation

Read more about Predicted Outputs in our blog post.

Explore The Demo

This walk-through focuses on the common workflow of modifying an existing document such as source code.

  • Load, type, or paste a document into the input window.
  • Describe the change you want in the prompt field, then submit.
  • Green output tokens were processed in parallel and appear almost instantly.
  • Red tokens mark minor mispredictions; the slowdown is typically negligible.
  • Plain text indicates portions without an active prediction, so they stream at normal speed.

Under The Hood

Predicted Outputs lives in Cascade Technology's vllmx repo, a light fork where we develop experimental features for vLLM before contributing them upstream. The feature integrates with vLLM's speculative decoding path and works with most models and configurations that already support speculative decoding.
